# Account-service

На момент 28.09.2026, данный сервис хранит в себе логику сфер:
1) Authentication и выдача JWT
2) Каталог - хранит в себе шаблоны предметов.
3) Инвентарь - содержится логика хранение предметов пользователя, с которыми он может взаимодействовать
4) Профиль - Работа с данными профиля пользователя. По факту, взаимосвязан с Auth, т.к они работают с одной базой данных
